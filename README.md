# Артём Германов — портфолио

Сайт: [legolite4.github.io/portfolio](https://legolite4.github.io/portfolio/)

Одностраничный сайт для стажировок, хакатонов, олимпиад и совместных кейсов. Визуальный язык близкий к [cu.ru](https://cu.ru/), без логотипа ЦУ.

## Запуск

```bash
npm install
npm run dev
```

Сборка в `dist/`:

```bash
npm run build
npm run preview
```

Папку `dist/` можно открыть локально. Базовый путь относительный (`./`), поэтому сайт работает и из подпапки.

- `index.html`, `src/` — страница
